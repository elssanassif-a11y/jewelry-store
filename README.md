 Aurelle – Jewelry Website

 1. Project Description
Aurelle is a luxury jewelry website designed to showcase beautiful jewelry collections and help customers discover pieces for themselves or as gifts.

 2. Technologies Used
- HTML: Used to create the structure and content of the website.
- CSS: Used for styling, layouts, colors, animations, and responsive design.
- JavaScript: Used to add interactive features and functions.
- Bootstrap 5.3.8:Used for responsive layouts, navigation, and grid systems.
- Font Awesome 6.7.2: Used to add icons to the website.

 3. Main Features
- Responsive website design.
- Navigation bar with links to different sections.
- Jewelry collections: bracelets, necklaces, rings, and earrings.
- New Arrivals section.
- Shopping cart buttons.
- Animated elements and hover effects.
- Customer reviews section.
- Find Your Match interactive quiz.
- Promotional countdown timer.
- About Us section.
- Footer with social media links.

4. How to Open and Run the Project
1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript, and image files are included.
4. Open `index.html` using Live Server or any web browser.
5. The website will open and be ready to use.

 5. Project Folder and File Structure
The project is organized into one main folder named Aurelle.

The folder contains `index.html`, which is the main file responsible for the website's structure and content.

It also contains `style.css`, which controls the website's appearance, including colors, layouts, animations, and responsive design.

The `script.js` file contains the JavaScript code used for interactive features and website functions.

The `README.md` file provides information about the project, its technologies, features, and instructions for running it.

Finally, the `Images` folder contains the product pictures and decorative images used throughout the website.

All files and images should remain in their correct locations so that the website works properly.
